# Paper figures

These figures are the published artwork used by the LongWoF-Bench paper
(arXiv:2608.23200v2, 2026-08-25). They are kept locally so the repository README
renders the same visuals without depending on a third-party image host.

- Source page: <https://arxiv.org/html/2608.23200>
- Figure 1: `overview.png`
- Figure 3: `evolved_gene_completion.svg`
- Figure 4: `gene_author_comparison.svg`
- Figure 5: `discovery_reuse_cost.svg`
- Figure 6: `workflow_type_gains.svg`

The figure captions and numerical claims belong to the paper cited in the root
README. If the paper receives a new version, update these files and the README
captions together.
