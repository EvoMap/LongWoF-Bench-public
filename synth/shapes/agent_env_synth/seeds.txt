# 160 seeds for agent_env_synth solution-first pipeline (v3-sf).
# Format: domain|task_idea
# Constraints: each scenario ships a bespoke package with >=2 non-obvious API
# behaviors (hidden conventions), a derivation chain depth >= 3, and >= 2
# independent output deliverables graded by pytest.
